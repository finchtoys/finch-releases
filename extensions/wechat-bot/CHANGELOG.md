# 更新记录

## 0.5.26

### 修复

- context_token 过期（锁屏超约 48h 无入站消息）导致 `sendMessage ret=-2 prepare failed` 推送失败：现在遇到该错误会自动去掉 context_token 重试一次（上游 issue #331 实测该字段按 API 定义可选），长间隔推送不再需要人工重新触发入站消息。
- 发送失败的错误信息现在携带 ret、errcode 与 errmsg 全文（errmsg 含凭证片段时自动回退固定标签，保持脱敏红线）。

## 0.5.25

### 优化

- 移除临时的 Agent 发送诊断工具及对应标题文案，不再额外占用工具上下文。
- 保留脱敏本地记录和错误诊断编号，发送逻辑、登录上下文、历史记录与定时任务不变。

### 验证边界

- 53 项模拟回归通过；类型检查、构建、产物语法检查通过。观察期结束，随本版发布 npm 并更新社区索引。

## 0.5.24（本地观察版）

### 修复

- 修正 0.5.23 对成功响应的过严判定：HTTP 成功、返回 JSON 对象且无非零业务码时允许省略 `ret`，与腾讯官方发送客户端语义一致。不再将这种响应误报为投递未知。
- 发送响应类型将 `ret` 改为可选；诊断保留实际缺失字段，不伪造 `ret=0`，不更改 0.5.23 的历史观察记录。
- 仍拒绝非零 `ret`/`errcode`、异常字段类型和非法响应；HTTP 错误、非法 JSON、超时不当作成功，不加入自动重试。
- 成功只表示服务端受理，不是手机送达回执；本次不重发已收到的消息、不刷新上下文、不要求重新扫码。

### 验证边界

- 53 项模拟回归通过；类型检查、构建、产物语法检查、小程序 doctor 与安装包检查通过。
- 补充省略零码、仅有服务端消息标识、缺省 `ret` 的非零 `errcode`、caption/媒体，以及真实 HTTP 解析链路的模拟回归。
- 使用模拟 fetch，不访问真实微信；实际投递继续沿用现有定时任务观察。仅本地安装，不发布 npm 或更新社区索引。

## 0.5.23（本地观察版）

### 优化

- `prepare failed` 改为中性错误分类，不再默认归因于上下文过期或建议重新扫码。
- 统一文字与媒体说明文字的 Unicode/UTF-8 无损分段；每段保守限制为 4000 码点及 4000 字节。
- 同一登录和收件人的发送串行排队，最多 20 个逻辑请求，避免正文、说明文字及媒体交错。
- 新增只读发送诊断：最近七天可见、最多存 100 条，写入时淘汰旧记录。仅保存大小、分段、接收快照版本、尝试次数、返回码和结果；不保存收件人、正文、凭证或服务端回显。

### 修复

- 发送失败通过异常链路传递，避免现有宿主漏传返回值 `isError` 后将失败工具调用记录为成功。
- 缺少明确成功码时报告投递未知，成功文案只确认接口受理，不伪称手机送达。
- 分段中途失败或取消立即停止；部分受理会明确标示，避免整段重复投递。
- 上下文读取与更新串行，失败写入标记为不可用，避免新 token 配上旧接收时间；旧版本已保存的上下文继续兼容。
- 诊断写入/日志异常不覆盖真实发送结果、不引发重试。

### 验证

- 49 项模拟回归通过（新增 22 项），覆盖分段、并发、取消、部分受理、未知响应、隐私、诊断故障与上下文写入中断；不访问真实微信或用户凭证。
- 类型检查、构建、产物语法检查、小程序 doctor 及安装包检查通过。
- 跨天定时投递的真实稳定性尚待观察，不将模拟测试当作实际送达证明。

### 观察边界

- 不清除现有上下文，不加入无 token 重试，不臆造 token 有效期或服务端配额。
- 不保证解决长期无入站消息后的主动推送资格限制；沿用现有定时任务继续观察。
- 此版先本地安装，不发布 npm 或更新社区推荐版本。

## 0.5.22

### 优化

- 文本、说明文字、图片、视频和文件共用发送校验，缺少消息上下文时提示先从微信给当前 Bot 发消息。
- 媒体读取、远程下载及 CDN 上传前检查发送上下文，避免无效的媒体处理。
- 区分未登录、缺少上下文、服务端准备失败、登录失效及发送期间登录切换；支持中英文提示。
- 错误保留 `ret`、`errcode`、限长且去敏的 `errmsg`；诊断日志记录上下文是否存在和接收时长，不输出 token 或消息内容。

### 修复

- 发送响应仅有 `errcode` 非零时也视为失败；说明文字失败后不继续发送媒体。
- 说明文字成功但媒体失败时报告部分成功，避免重试造成说明文字重复。
- 发送上下文按 bot 和登录凭证隔离，退出/重新登录时清理，拒绝旧轮询响应写入新登录上下文。
- 移除历史 Session/turn 中的 token 回退，发送时只取当前登录下最新上下文。

### 升级注意

- 新发送上下文使用系统安全存储，新增 `wechat.context.*` 权限；不可用时不回退明文。若升级后提示未声明 secret access，请禁用后重新启用并确认权限，仅重载可能不足。
- 旧上下文没有登录归属，升级时移除旧 token。请从微信给当前 Bot 再发一条消息；历史会话和任务保留。
- 不加入无 token 自动重试，不臆造服务端 token 有效期。

### 验证

- 新增 27 项模拟回归测试；类型检查、测试与构建通过。
- 本地安装后完成微信 → Finch 接收和 Finch → 微信真实发送验证，手机端已确认收到测试消息。
