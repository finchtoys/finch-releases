# 更新记录

## 0.5.22

### 优化

- 文本、说明文字、图片、视频和文件共用发送校验，缺少消息上下文时提示先从微信给当前 Bot 发消息。
- 媒体读取、远程下载及 CDN 上传前检查发送上下文，避免无效的媒体处理。
- 区分未登录、缺少上下文、服务端准备失败、登录失效及发送期间登录切换；支持中英文提示。
- 错误保留 `ret`、`errcode`、限长且去敏的 `errmsg`；诊断日志记录上下文是否存在和接收时长，不输出 token 或消息内容。

### 修复

- 发送响应仅有 `errcode` 非零时也视为失败；说明文字失败后不继续发送媒体。
- 说明文字成功但媒体失败时报告部分成功，避免重试造成说明文字重复。
- 发送上下文按 bot 和登录凭证隔离，退出/重新登录时清理，拒绝旧轮询响应写入新登录上下文。
- 移除历史 Session/turn 中的 token 回退，发送时只取当前登录下最新上下文。

### 升级注意

- 新发送上下文使用系统安全存储，新增 `wechat.context.*` 权限；不可用时不回退明文。若升级后提示未声明 secret access，请禁用后重新启用并确认权限，仅重载可能不足。
- 旧上下文没有登录归属，升级时移除旧 token。请从微信给当前 Bot 再发一条消息；历史会话和任务保留。
- 不加入无 token 自动重试，不臆造服务端 token 有效期。

### 验证

- 新增 27 项模拟回归测试；类型检查、测试与构建通过。
- 本地安装后完成微信 → Finch 接收和 Finch → 微信真实发送验证，手机端已确认收到测试消息。
