# WeChat Bot · 微信 Bot

把微信变成你随身携带的 Finch 入口。人在外面、没开电脑的时候，也能用微信直接跟 Finch 对话、派任务、收结果。

## 这个扩展能做什么

你平时可能习惯电脑上跟 Finch 聊，但很多时候灵感或需要处理的事出现在通勤路上、开会间隙、饭桌上 —— 这时候打开微信就行：

- 给微信里的 Finch 发一句话、一段语音，它会读懂并处理，处理完直接在微信回复你。
- 发照片或文件过去，让 Finch 帮你看看、分析、整理。
- Finch 回复中包含的图片会自动发送到微信对话框，支持发送图片、视频、文件等媒体资源。
- 让 Finch 把一件正事交给某个专属 Space（比如「读书笔记」「产品需求」）去处理，处理完自动发微信通知你结果。
- 之前发的消息、Finch 的回复都会留在这个微信对话里，随时能往回翻。

简单说：微信收件箱里那个对话，就是一个完整的 Finch 会话，只是入口换成了微信。

## 快速上手

### 登录

打开微信收件箱对应的对话，在设置菜单里点击「登录微信」，会弹出一个二维码 —— 用你自己的微信扫码确认即可，跟平时网页版微信登录一样。登录后，这个微信账号发来的消息都会由 Finch 接收和回复。

### 开始对话

登录成功后直接发消息就行，文字、语音、图片、文件、视频都支持。Finch 处理完会把结果发回你的微信，回复中如果包含本地图片也会自动上传并发送到微信对话框。

### 主动发送前先建立消息上下文

扫码登录只建立登录状态。请先从手机微信给当前 Finch Bot 发一条消息，确认 Finch 收到后，再让 Finch 主动发送通知、晨报或文件。

- 没有消息上下文时，扩展会直接提示先从微信发消息，不会继续调用发送接口或上传媒体。
- 有上下文但接口返回 `ret=-2 / prepare failed` 时，会提示上下文可能失效，并保留 `ret`、`errcode`、`errmsg` 供排查；不会直接将所有 `-2` 当成限流或确定为 token 失效。
- 如果说明文字已发送、媒体发送失败，错误会标明部分发送成功，重试时不要重复说明文字。
- 重新扫码登录后，请再从微信给当前 Bot 发一条消息。

### 换个新话题

如果想抛开之前聊过的内容，重新开始一个话题，直接跟 Finch 说「开个新对话」即可。之前的记录不会丢，还留在微信收件箱里，随时可以翻回去看。

### 把任务交给某个 Space

如果这件事更适合放到某个专属的 Space（比如需要那个项目的资料和规则），可以直接跟 Finch 说，比如「把这件事交给读书笔记那个 Space 处理」。Finch 会在对应 Space 里单独跑这个任务，完成后主动发微信通知你结果，你不需要一直等着。

### 重新登录或退出

如果换了手机、扫码过期，或者想换一个微信账号，在设置菜单里选择「重新登录」；不想继续使用了，选择「退出」即可。

## 使用条件

- 一个可以扫码登录的微信账号。
- 已启用本扩展的 Finch 桌面版。

## 0.5.22 升级说明

发送上下文按 bot 身份与登录凭证隔离，token 保存到系统安全存储；普通存储只保存接收时间，不臆造服务端有效期。退出或重新登录时会清理发送上下文。

本版新增 `wechat.context.*` 安全存储权限。若 Finch 提示授权变更，请确认该权限；安全存储不可用时不会回退到明文存储。

升级后如果出现 `has not declared secret access`，请在小程序面板禁用微信 Bot 后重新启用，并确认新增权限；仅重载可能没有刷新运行实例的权限声明。重新启用后，从微信给当前 Bot 再发一条消息。

旧版本的上下文未记录登录归属，升级时会移除旧 token（包括历史映射里的 token），不迁移到新缓存。升级后请从微信给当前 Bot 再发一条消息。历史会话、映射及 Space 任务不会删除。

## 隐私说明

登录状态和消息记录只保存在你自己电脑本地，不会被上传或共享。二维码和登录过程也不会进入 Finch 的对话上下文，不用担心被模型「看到」你的账号信息。
